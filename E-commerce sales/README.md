### 📊 Key Analysis

* Total Sales and Profit
* Sales trends over time
* Regional performance
* Product and category performance
* KPI tracking
* Business performance analysis

**Tools Used:** Power BI, Power Query, DAX

## 📁 Project Structure

The repository is organized as follows:

```text
E-Commerce-Executive-Dashboard/
│
├── data/
│   └── e-commerce-data.csv
│
├── images/
│   └── dashboard.png
│
├── E-COMMERCE EXECUTIVE DASHBOARD.pbix
│
└── README.md
```

### 📂 File Description

* **`data/`** – Contains the dataset used for the Power BI analysis.
* **`images/`** – Contains screenshots of the Power BI dashboard.
* **`E-COMMERCE EXECUTIVE DASHBOARD.pbix`** – The main Power BI report file containing the dashboard, data model, DAX measures, and visualizations.
* **`README.md`** – Contains the project overview, documentation, key analysis, and insights.
